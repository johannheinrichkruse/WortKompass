# WortKompass

Deutschsprachiges Worträtsel für Smartphone, Tablet und PC.

## Spielvarianten

- 5 Buchstaben: 6 Versuche
- 6 Buchstaben: Leicht (7 Versuche) oder Mittel (6 Versuche)
- Tagesrätsel und unbegrenzte freie Spiele
- Umlaute sowie ß als eigenständiger Buchstabe
- Freiwilliger Spitzname und ausschließlich lokale Statistiken
- Export der Wortlisten und Statistiken

## Start und Veröffentlichung

Die Anwendung ist vollständig in der Datei `index.html` enthalten. Für die Veröffentlichung GitHub Pages unter **Settings → Pages → Deploy from a branch → main → /(root)** aktivieren.

## Hinweise

Der Wortbestand wurde überarbeitet, aber eine vollständige lexikografische Einzelprüfung aller Wörter steht noch aus. Es können daher noch ungeeignete Lösungen oder fehlende zulässige Eingabewörter vorkommen.

Persönliche Spielstände und Statistiken werden lokal im Browser gespeichert und nicht zwischen Geräten synchronisiert. Das öffentliche Repository enthält den Quellcode und die integrierten Wortlisten.
